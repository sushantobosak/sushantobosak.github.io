# Sushanto Bosak - Academic Website

This is a simple GitHub Pages academic website.

## How to publish on GitHub Pages

1. Create a GitHub account at github.com.
2. Create a new public repository named exactly:
   `yourusername.github.io`
   Example: `sushantobosak.github.io`
3. Upload these files into the repository:
   - `index.html`
   - `style.css`
   - `README.md`
4. Go to repository Settings > Pages.
5. Under "Build and deployment", choose:
   - Source: Deploy from a branch
   - Branch: main
   - Folder: /root
6. Save.
7. Your website should appear at:
   `https://yourusername.github.io`

## Editing

Edit `index.html` to update your content.
Edit `style.css` to change the design.
